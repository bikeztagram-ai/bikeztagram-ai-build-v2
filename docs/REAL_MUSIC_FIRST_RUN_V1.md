# First Real Music Run V1

## Brief
Create an original 180-second cinematic biker-rock song with gritty lead vocal, strong memorable chorus, dark opening, escalating build, major chorus/drop and large final section.

## Required evidence
- actual generated audio
- runtime/model/version
- generation time
- prompt/request record

- quality evaluation

No pass from metadata, mock output or placeholder response. The file must be playable and evaluated as music.
