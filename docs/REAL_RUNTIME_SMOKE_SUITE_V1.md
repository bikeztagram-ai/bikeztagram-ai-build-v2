# Real Runtime Smoke Suite V1

## Music
1. Check runtime health.
2. Submit the compiled 180-second song request.
3. Require a playable audio result.
4. Record model/runtime/version, elapsed time and provenance.
5. Evaluate musical structure and quality.

## Video
1. Check runtime health.
2. Submit the motorcycle image-to-video fixture.
3. Require a playable video result.
4. Record model/runtime/version, elapsed time and provenance.
5. Evaluate identity preservation and natural motion.

## Failure rule
Connection failure, unavailable runtime, placeholder response or missing media is a BLOCKED result, not a pass.
