# Phone → Generation Flow V1

1. Android submits a creative brief.
2. Vercel validates and creates a bounded job.
3. A remote worker claims the job.
4. Worker generates music/video outside the Vercel request lifecycle.
5. Worker returns normalized media metadata and provenance.
6. Vercel records status/result metadata.
7. Bikeztagram evaluates and revises when needed.
8. Final media enters the existing editor/timeline.

No heavy inference is performed by the phone or ordinary Vercel request handler.
