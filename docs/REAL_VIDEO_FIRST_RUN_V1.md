# First Real Video Run V1

## Fixture A
Use a supplied motorcycle reference and request short natural cinematic movement while preserving recognisable geometry, colour and key details.

Use person + motorcycle references and request an original cinematic sequence: approach → mount → ride away.

## Required evidence
- actual generated video
- runtime/model/version
- generation time
- input/reference record
- continuity evaluation

- provenance/licence record

## Acceptance
No pass from metadata, mock output or placeholder response. The file must be playable and visibly evaluated.
