# Provenance & Rights Contract v1

Bikeztagram should treat media origin, rights and consent as first-class data throughout the creative pipeline.

## Principles

- User-uploaded does not automatically mean user-owned.
- Unknown rights are review-required, not automatically allowed.
- Consent and rights are separate signals.
- Identity/deception operations require stronger consent checks.
- AI-generated output should be disclosed where appropriate.
- Provenance records describe origin/history; they do not prove legal ownership.
- Export should retain the provenance chain where technically feasible.

## Pipeline position

`intake -> provenance record -> rights/consent decision -> creative planning -> generation/editing -> output check -> export provenance`

This module is intentionally isolated first so it can be reviewed before integration into the production media pipeline.
