# Music Model Benchmark V1

Compare ACE-Step 1.5 and YuE using the same Bikeztagram briefs.

## Full-song tests
- 3 minute original song with verses, chorus, bridge and finale.
- Dark cinematic/biker track with a strong chorus and major drop.
- Vocal + accompaniment consistency across the full song.

## Control tests
- Exact BPM/key/duration.
- Planned drop timing.
- Section-level regeneration.
- Reference/in-context guidance where legally appropriate.
- Stem separation/editability where supported.

## Quality
Score songwriting, melody, vocal realism, arrangement, instrument realism, structure, dynamics, mix/master, prompt adherence, continuity and editability.

## Legal gate
Record model licence, weights licence, training-data statements and attribution requirements before production use. Never assume an open model automatically grants every commercial right for every use case.
