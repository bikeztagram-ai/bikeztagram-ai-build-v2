# Bikeztagram AI — Generation Benchmark Matrix V1

## Video
1. Bike image → natural motion; preserve recognisable bike.
2. Person + bike → approach, mount, ride away.
3. Arbitrary object → controlled motion.
4. Multi-subject interaction.
5. Original world creation.
6. Real → generated bridge → real.
7. Multi-scene identity continuity.

## Music
1. Cinematic build → major drop → finale.
2. Dark electronic track with controlled energy curve.
3. Exact reveal/drop timing.
4. Section regeneration without destroying the rest of the track.
5. Variation generation and ranking.

## Scoring
Record model/version/runtime, hardware, generation time, prompt fidelity, subject continuity, motion/audio quality, technical validity, licence evidence and output location.

## Rule
Do not promote a runtime based on a single impressive example. Use the same matrix across candidates and retain evidence for every result.
