# Music Runtime Selection Matrix V1

Score ACE-Step 1.5 and YuE on the same Bikeztagram fixtures.

| Dimension | Weight |
|---|---:|
| Songwriting / prompt fidelity | 20 |
| Vocal quality | 15 |
| Melody / hook | 15 |
| Arrangement / dynamics | 15 |
| Instrument realism | 10 |
| Mix / master | 10 |
| Timing / structure control | 10 |
| Editability / regeneration | 5 |

Also record generation time, hardware/VRAM, failures and licence/provenance evidence.

No runtime is selected from a single sample. The winning runtime must pass the real-output evidence gate and remain swappable behind the Bikeztagram Music Studio contract.
