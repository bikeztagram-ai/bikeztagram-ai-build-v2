# Creative Engine Integration Matrix

## Production flow

1. **Understand** — analyse user assets and build subject manifest.
2. **Direct** — convert the creative brief into story, shot, music and generation intent.
3. **Music** — generate/rank soundtrack candidates and expose actual musical events when measured.
4. **Scenes** — generate optional scenes, inserts, transitions or fully synthetic sequences.
5. **Assemble** — combine real and generated media into one timeline.
6. **Render** — use the protected existing renderer until a verified replacement exists.
7. **QA** — evaluate technical and creative quality.
8. **Revise** — make bounded targeted changes based on QA.
9. **Export** — produce the requested social formats.

## Evidence rule

Architecture contracts may be implemented before model runtimes, but no model is considered production-ready until it has passed the benchmark harness and commercial/licensing review.

## Protected systems

- Existing renderer baseline.
- Blob/Gemini server contracts.
- Existing verification conventions.
- Current working cinematic-music baseline.

## Integration rule

Experimental branches remain isolated until contract verification, static review, and representative runtime testing are complete. Never merge generated-media experiments directly into production.
