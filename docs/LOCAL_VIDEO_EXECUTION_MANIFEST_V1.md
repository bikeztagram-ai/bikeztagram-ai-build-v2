# Local Video Execution Manifest V1

Vercel is intentionally not part of this experimental execution path. Git remains disconnected from Vercel while local generation is benchmarked.

Required execution evidence:
- selected runtime and exact version
- model/version and licence/provenance
- hardware/backend
- compiled Bikeztagram scene request
- actual video output path
- elapsed generation time
- subject/continuity evaluation

Promotion rule: real generated video must exist before the runtime is considered operational.
