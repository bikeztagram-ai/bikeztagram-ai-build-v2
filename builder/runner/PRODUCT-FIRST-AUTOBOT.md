# Product-first AutoBot

The primary AutoBot path is product engineering. The local coding model should spend its run improving Bikeztagram AI, not improving the builder itself.

The feature brain already carries previous failure evidence into bounded retries, project memory and lessons. A failed attempt must remain a failure; only verified product changes advance the backlog.

Self-improvement is reactive: when repeated product-building failures expose a real weakness in the builder, that weakness can be fixed separately and then returned to product work.
